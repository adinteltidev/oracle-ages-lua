# Corrida 2x

Requer a nova build com as funções Lua `on_input` e `run`.

- macOS/Windows: segure **Shift esquerdo** ou o **ombro direito** do controle.
  É possível remapear em Settings → Controls → Run (mod).
- Switch: segure o **clique do analógico esquerdo (L3)**.

Copie esta pasta inteira, chamada `corrida`, para a pasta `mods` do jogo e
reinicie o aplicativo. No macOS C + Lua fase 7, o destino padrão é:
`~/Library/Application Support/oracles-decomp/oracles-lua-phase7/mods/corrida/`.
No Switch fase 7: `sdmc:/switch/oracle-ages-lua-phase7/mods/corrida/` para Ages,
ou `sdmc:/switch/oracle-ages-lua-phase7/seasons/mods/corrida/` para Seasons US.
Seasons Europe usa `seasons-eu/mods/corrida/`.

Soltar o botão restaura o movimento original. A corrida é 2x a caminhada normal
do terreno e não acumula com Pegasus nem consome sementes. Não se aplica a gelo,
água, saltos, montarias, recuo por dano, menus, transições e áreas de visão lateral.
Desinstale removendo a pasta e reiniciando o aplicativo.
