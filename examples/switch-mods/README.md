# Switch mod examples

Copy only the desired package directory into `DATA/mods/`. These files are
packaged outside the installed game directory; no example is enabled by packaging.
`overlay-info` draws a room label; `room-reader` reads room/camera/sprites.
`api2-demo` changes a reward mapping: use a disposable save when testing it.
Its optional identity write is off by default and exercises the write queue.
All examples use the same API as the desktop. Project LICENSE applies.
